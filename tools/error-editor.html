sCure - Languages & Errors Editor

English errors live in errors.json; every language of the screen lives in one file, languages.json.

How to use this editor

  1. Click Load files, or drop them below. Load sCureBox-CS/config/errors.json to edit the English errors, and sCureBox-CS/config/languages.json to edit the other languages. You can load both together.
  2. Pick the language at the top.
    • English edits the error registry: title, description, steps, support link and repair video.
    • Any other language edits its translation of the errors, the screen texts and the firmware messages. The English is shown next to each field.
  3. Fix every red mark before saving:
    • A placeholder such as {0} or {1:0.#} is the number or name the screen fills in. Keep each one.
    • A translated error must have as many steps as the English.
  4. Save, then copy the files back to sCureBox-CS/config/. The machine shows the change after a firmware install. Settings > Language lists every language in languages.json.
