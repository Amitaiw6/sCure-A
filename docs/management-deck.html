1 / 2 sCure Box · System Architecture

Full-Stack Control System — Touchscreen to I/O

Embedded control platform for a UV cure chamber: lamps, heater, fans, vent damper (servo), door interlock, RGB status strip and temperature sensors — one closed control loop from the UI down to the pins.

HMI React · TypeScript · Vite Kiosk UI — cure programs, materials, process reports
▶REST / HTTP
Control Server Python · Flask Process state machine, safety logic, data layer (PostgreSQL)
▶io_bridge
I/O Controller Python drivers Real-time hardware access over I²C; simulation mode off-target
▶I²C / GPIO / PWM
Plant Raspberry Pi UV · heater · fans · damper servo · door lock · sensors

Safety & Fault Handling

  • Door-open aborts a running process (Err 6016) after a 10 s on-screen grace countdown
  • 2 s status watchdog; heater-fan tach monitoring with glitch filtering
  • Central error registry — unique code per fault, surfaced in UI and SRS

Process & Data

  • Measured chamber temperature drives the cure ramp; UV gated on target temp
  • Programs, materials and cure reports persisted in PostgreSQL (JSON fallback)
  • Connectivity watch: TCP 443 probe every 5 s with UI status indication

Deployment & Verification

  • Raspberry Pi kiosk — boots straight into the app, unattended
  • Windows build with full hardware simulation for development and demos
  • Dedicated QA harness covering every feature; SRS with flow & sequence diagrams
